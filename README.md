# SweetBakery – Bakery Management System

SweetBakery is a web-based bakery management application developed using ASP.NET Core MVC. The project is designed to simplify bakery operations through a centralized system for managing products, categories, customers, and orders.

## Features

- Product management
- Category management
- Customer management
- Shopping cart functionality
- Order management
- Database integration
- Responsive web interface

## Technologies Used

- **Backend:** C#, ASP.NET Core MVC
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework Core
- **Development Environment:** Visual Studio

## Database

The application uses Microsoft SQL Server for data storage and Entity Framework Core for database operations and migrations.

## Getting Started

1. Clone this repository.
2. Open the `.csproj` file in Visual Studio.
3. Configure your local SQL Server connection string in `appsettings.json`.
4. Restore the NuGet packages.
5. Apply the Entity Framework Core migrations if required.
6. Run the application.

## Project Purpose

This project was developed as part of an academic application development project to gain practical experience in ASP.NET Core MVC, database management, and full-stack web development.
